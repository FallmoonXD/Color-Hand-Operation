# 0.3.6 · 无手图标、原版文字与全局预览

2026-11-06，OnePlus PKR110 / ColorOS 17。版本 `0.3.6-palette-preview`，versionCode 9，包名 `dev.edgeflow`。

## 图标

移除手部及平面屏幕，以本机天气、钱包、OPPO 健康的实际启动图标为材质参考，采用有厚度的冰蓝边框与珊瑚滑动弧带。三款参考的真实 manifest 入口与资源见 [采集记录](coloros-weather-wallet-health-icons.md)。彩色图标是内置 imagegen 生成的 RGBA 插画，配合原生自适应背景与 6% 前景内缩；不是从 ColorOS 提取的渲染管线。MD3 和通知仍为独立的不透明矢量路径。

原始素材、提示词、生成与包装校验见 [图标记录](volume-icon-validation.md) 和 [提示词](../design/icon-generation-prompt.txt)。已用设备 Android 框架绘制安装 APK 的普通自适应与 monochrome 图层，并检查圆形、圆角和 72/44px 预览。手部路径已从当前生成规范删除，重新生成不会恢复旧图。

## OHO+ 文字和边缘预览

依据用户提供的 OHO+ 9.3.13.0 APK 中文资源 `resources/res/values-zh-rCN/strings.xml` 与控制器布局，恢复“触摸宽度”“大小”“位置”和“小—大”“低—高”“短—长”等原版标题、端点。删除新增的 dp、比例和阈值解释；数值仍提供给无障碍服务。此前明确要求保留的振动百分比和“0：使用系统触觉反馈”继续保留。颜色面板使用原版“透明度级别”名称，存储语义不变。

删除内嵌手机示意图和滚动时出现的浮动手机卡。`HandlePreviewView` 只保留组色计算，不再是 View。主页和触钮配置页由服务直接显示真实位置/宽高的半透明边缘区域：主页显示已启用的触钮，单侧配置按现有对齐状态显示对应区域。预览窗口不接收触摸、不修改实际输入区域；拖动使用草稿，取消恢复已保存位置。进入其他设置页、后台或息屏时清理。

实机发现 `NEW_TASK | CLEAR_TOP` 可让旧 MainActivity 在新实例恢复后才销毁。已通过 `HandlePreviewOwner` 为设置预览分配实例归属：接管和清理都在服务主线程执行，旧实例只能清理自己的预览。临时预览的 10 秒超时也不能删除后续设置页预览，服务断连/息屏仍强制清理。

## 直接调色板

颜色行以当前色块替换导航箭头，点击直接展开网格/色环调色板，取消原来的颜色中间页。参考的是本机相册 17.10.41 的涂鸦工具：使用其 120 色数字表、色环/SV 方块和透明渐变条尺寸，自行实现绘制与交互，没有打包相册私有类或库。范围和源路径见 [相册调色板记录](gallery-color-palette.md)。

调色板支持 HEX、色相、饱和度、明度与全局透明度级别。RGB 操作保留 ARGB 的 A 字节，全局可见度仍单独保存，不把乘积写回颜色。预览不写偏好，确认退出后统一提交，取消/后台恢复原值；非法 HEX 禁用确认并提示错误。主页联动配置写双侧，单侧配置只写对应侧。

## 验证

离线构建成功。调色板状态 324 项断言、配置/几何及预览归属 141 项断言通过。配置 harness 使用 Gradle 的 mockable Android jar；原始 SDK stub jar 不能作为运行时，复现方式见 [配置验证](config-validation.md)。

实机脚本 `tools/verify_global_preview.py` 已通过：

- 真实预览位置跟随滑条，普通点击保持同一控件实例；竖向滚动不改参数。
- 拖动草稿改变屏幕边缘宽度，但不落盘；取消恢复原几何。
- 预览超过原临时 10 秒期限后继续显示；离页/后台清除，返回恢复。
- 预览为不可触摸窗口，测试前后配置一致。

`tools/verify_color_palette.py` 已通过：

- 非法 HEX 不能确认；色环和网格选色保留输入颜色原有 alpha。
- 草稿颜色、全局透明度修改后取消，没有偏好写入。
- 确认半透明 ARGB 和独立透明度级别时，主页正确更新双侧。
- 临时取消触钮对齐后，单侧确认只更新对应侧颜色。
- 所有测试值恢复，包括原本不存在的颜色/对齐键。恢复时仅处理测试触及的键，重新启动应用并保留已授权的无障碍服务。

本机证据：`verification/palette-preview-geometry-validation.json`、`palette-color-validation.json`、`palette-bounds-validation.json` 及 `palette-*.png`。这些证据不参与运行时。

边界实测另通过三次快速 Home/CLEAR_TOP 页面重建：旧实例清理未再删除新预览。系统字号 1.6 与键盘弹出时，确认/取消按钮始终可用，编辑内容可滚动；系统字号随后恢复原值。离开设置后预览全部消失，左右短滑仍能执行各自的音量动作，测试音量已恢复。
