# 快速启动与键盘快捷方式子菜单

修改 `QuickLauncherOverlay`、`KeyboardShortcutsOverlay` 和 5 个 Settings 图标，沿用原面板材质、手势和配置格式。共享菜单实现见 `ColorDialogBuilder` / `ColorPopupMenu`。

## 快速启动

- “添加”“选项”和入口长按管理使用真实点击控件作为 ColorPopupMenu 锚点。删除项使用分隔与危险操作色。
- 应用、系统动作、文件夹目标使用统一的列表：40dp 图标，16sp/500 主文字，13sp/400 辅助文字，64–72dp 行高；多选采用 ColorCheckBox，语义随选中状态更新。
- 系统动作按 ActionCatalog 分组，已退役的 `app_launcher` 不重新出现在候选里；已有旧入口和当前不可用的应用不会因保存其他选项而丢失。
- 应用名称和图标由 worker 读取；图标预先栅格化为 40dp，取消或窗口退出后释放。已经关闭的选择窗不会接收旧异步结果。
- “新建文件夹并移入”先编辑名称；仅确认有效名称后创建与移动。取消不产生空文件夹，也不移动原入口。
- 文件夹名校验仍为原有 256 字符边界。错误在输入框下显示，保留编辑窗口。

## 键盘快捷方式

主列表将名称和组合键分为两行；每行右侧“编辑名称”按钮打开锚定菜单，修改、排序、删除不再堆叠多个列表对话框。添加与修改表单保留原列表，取消回原列表；只有保存退出完成后才更新数据。名称错误归属名称输入框，组合键错误归属组合键输入框。

原有包名空间、组合键解析与导入格式保留；界面新增时遵守已有导入格式的 200 项上限。实际执行仍先关闭窗口，核对当前前台应用，再调用原键盘输入路径。

## 输入与窗口

非输入选择窗继续使用 `TYPE_ACCESSIBILITY_OVERLAY` 和 `FLAG_NOT_FOCUSABLE`。短菜单也显式使用相同类型与非焦点配置；只有名称/组合键编辑窗允许聚焦与 IME。

子窗口打开时，父浮层操作被阻挡。父视图锁存整次触摸的阻挡状态，并比较 `MotionEvent.downTime` 和子窗关闭时刻，防止动画关闭后 UP 或关闭动画为零时透传到父按钮。下一次独立触摸立即恢复，没有固定防抖延迟；无障碍直接点击另外受到入口状态检查。子菜单内部完成后的保存、移动、修改回调不经过父入口阻挡。
