# CHO 逐页、逐组件 COUI 选型

审阅基线是 2026-11-07 的 `02b4999`。下表记录当时逐项选定的方向，试用版的实际改动见[试用进度](#试用进度)。文中的 COUI 类名指本机 ColorOS 17 的参照实现；CHO 可以用自己的 View、Drawable 和公开 Android 接口兑现相同的布局、交互语义和回退行为。

**优先改变三处结构。** 面板设置应当能从首页直接找到；为手势挑动作应使用可搜索的整页目录；快速启动、小组件、快速工具要分别采用启动器、桌面编辑器和控制中心的界面。三者都在其他应用上方出现，但执行的任务完全不同。

- **设置和 COUI。** 对照 PKR110 的显示、声音实机截图与控件树，Settings 的 `display_settings_oplus.xml`，以及 `com/coui/appcompat` 中的 preference、searchview、segmentbutton、panel、poplist、toolbar、edittext、seekbar 和 bottomfloatingedittoolbar。显示页用预览卡选择外观、跳转行进入下级设置、滑条调整连续量。声音页把多条相关音量滑条放在一张实色卡中。这些是具体选型的参照。[原生资料索引](coloros17-native-ui-research.md)
- **系统功能的参照。** 侧边栏对照 `PanelMainView`、`AllAppPanelView`、`EditPanelView`、`SidebarPanelMaterialLayout`；最近任务对照 Launcher 的 `RecentsView`、`TaskView`；小组件目录对照 `widgets_full_sheet.xml`、`oplus_widget_cell_content.xml`；媒体区对照 SystemUI 插件的 `MediaPlayerCardPageRootView`；调色对照相册的 `de_toolkit_color_picker_portrait.xml`。这些实例提供结构与渲染依据，Android 的 AppWidget、任务快照和系统窗口仍有各自的能力边界。[调色板调查](gallery-color-palette.md) · [面板能力记录](material-policy.md)
- **视觉证据。** 本轮重新查看了已保存的原生显示、声音样本，以及 CHO 的首页、触钮页、动作选择、色板、更多菜单、确认框、工具面板和编辑页。文件夹、任务、触控板、快捷键、小组件编辑等同时参考历史实机图和当前代码。源码覆盖全部入口，本轮没有重新上机逐页测量；历史图只用于识别布局问题。[实机资料的使用范围](coloros17-native-ui-research.md)

## 渲染选型

| 下文用语 | 具体怎么画 | 使用条件和回退 |
| --- | --- | --- |
| 实色设置页 | Settings 的页面底色、COUI 分组卡、标题、图标、分隔、选中和禁用色。普通 View 和有界 Ripple | 静止的卡片、列表、表单直接绘制。名称和状态用系统字体及用户字号；主题资源缺失时用同一层级的亮暗色板 |
| 同窗口按钮 | 让滚动内容经过按钮下方，Oplus View 背景效果只作用于圆形按钮，前景图标独立绘制；圆形轮廓使用 Oplus 边缘与阴影接口 | 返回和更多按钮确有内容可取景时启用。分别响应模糊、轮廓开关；静止纯色处或能力不足时用主题圆底。长列表本身保持实色 |
| 独立菜单或选择层 | `COUIPopupListWindow` 的锚定菜单，`COUIListBottomSheetDialog` 的短列表，`COUIAlertDialogBuilder` 的确认框。使用各自 ViewRoot 的圆角窗口背景 | 菜单、确认框、底部面板在已测固件上的参考半径分别是 160、200、400 px。只处理卡片范围。无模糊、软件绘制或接口失败时，背景和前景一起切到不透明主题；含输入的窗口单独适配 IME |
| 跨应用主面板 | 与侧边栏、音量面板一样，由主窗口持有背景捕获和合成；子按钮、滑条、图标画在这层之上 | 快速工具、音量、小组件主体采用实测材质。新建列表、按键、圆点不各自订阅捕获。普通浮层的二级菜单优先用独立窗口材质；捕获失败时即时回到可读底色 |
| 直接绘制与外部内容 | 扇区、箭头、指针、把手、棋盘格用 Canvas 或矢量；应用图标、任务快照、AppWidget 和系统界面由生产方绘制 | 保留输入坐标、前景清晰度和实际内容比例。只把移动、缩放或透明材质放在真正需要它的对象上 |

现有项目已验证 Oplus 同窗口背景、ViewRoot 菜单、跨应用捕获是三条不同的路径。下文指定**谁拥有背景**，可以据此检查是否误给正文加模糊，或让一个子菜单新增了捕获客户端。[渲染实现与实机对照](coloros17-rendering-plan.md)

## 设置与编辑页面

| 页面／入口 | 选定的风格与组件 | 结构决定、原因和必须保留的行为 |
| --- | --- | --- |
| `home` 总览 | Settings 功能首页，固定品牌标题、总开关卡、触钮说明、成对触钮列表和分组跳转行。更多按钮用同窗口效果 | **重排。** 顺序为启用状态与服务状态、触钮组、面板与工具目录、手势与高级设置。缺服务时只显示一个可操作提示；总开关和实际服务连接分别表达。总开关下方保留灰色说明。添加放在组尾，移除放在组管理入口；到 1 对／3 对边界时说明可用操作 |
| 拟增「面板与工具」目录 | 单一首页跳转行进入实色 Settings 目录，每个工具为 `COUIJumpPreference` 式行，显示名称与一句用途 | 一组放快速工具、小组件、快速启动、任务切换器；另一组放触控板、导航键、键盘快捷方式。与动作齿轮复用同一设置目的地；从目录返回首页，从齿轮返回原动作和位置。这样即使配置了三对触钮，首页也只增加一行 |
| 首页联动几何区 | 分组跳转行「触钮范围」进入几何编辑；编辑页使用实色滑条卡和真实边缘预览 | **从总览移出。** 当前仅一对且已对齐时，首页直接出现宽度、大小、位置、颜色，改变对齐方式又会移动这些控件。目标让“范围”有固定入口；侧边详情也能进入同一组配置，不复制存储。保留左右联动、实时预览、取消恢复和原有配置 |
| `left`、`right` 主触钮 | 每侧独立详情；短滑三行、长滑总开关及三行、外观／范围组。动作行用 `COUIJumpPreference` 式标题＋当前动作＋方向图标 | **重组。** 直滑、上斜、下斜按物理边显示，当前动作写在副标题。长滑关闭时收起三行；对齐是独立开关。宽度、大小、位置、颜色在同一编辑入口；任何几何联动明确标出“同时修改左右侧” |
| `extra_left`、`extra_right` 第二对；`extra2_left`、`extra2_right` 第三对 | 同一侧边详情模板；标题含组名，保留自己的开关、六个动作位置和所在组的对齐状态 | **共享结构，保留差异。** 额外触钮只提供源码支持的大小、位置和颜色，宽度由主触钮规则决定。增加或移除的是一对；已有动作数据、遇到重叠时的触发优先级都随原逻辑 |
| `advanced` 条件 | Settings 分类页；“应用例外”用跳转行，横屏、通知面板、桌面、键盘四种隐藏条件用 `COUISwitchPreference` 式整行开关 | **保留独立页。** 分组标题给出“在这些场景隐藏触钮”，单项按场景命名；横屏描述是隐藏条件，不应误读为允许旋转。开关独立写入，切换后无需重建整页 |
| `gestures` 识别与振动 | 声音设置式实色参数组；短／长快捷操作用开关；距离、持续时间、振动强度用 COUI 滑条＋数值，角度用跳转行 | **整理依赖。** 分开短滑、长滑和触感；长滑区按可用配置出现。快速振动、自定义振动、强度是不同控制。距离显示 dp，持续时间显示 ms；保留旧立即触发、旧振动强度及 0 值语义。拖动与滚屏竞争时仅提交有效抬手 |
| `angle` 角度编辑 | 实色专用编辑页；页首一个左右视角分段控件 `COUISegmentButtonLayout`，短滑、长滑各一块独立 Canvas 图 | **换视角控件。** 当前两幅图各有镜像按钮，但修改的是同一个视角。只留一个明确选择器，四个边界、扇区、方向箭头、选中值继续直接绘制。支持拖动、键盘／读屏逐点调整；镜像只改观看方向，不改存值 |
| `exceptions` 应用例外 | 全页搜索式**多选**应用目录；固定 `COUISearchBar`、真实图标、名称、`COUICheckBox`、可回收列表 | **替换一次性通长卡片。** 每一行和复选标记指向同一开关，可即时保存。搜索只过滤显示，隐藏结果保留选中；区分原始列表为空、筛选无结果、加载失败。卸载后不把同名应用认作同一包 |
| 手势方向 →「选择操作」 | **全页动作目录**；固定标题和搜索，分组单选行，行尾设置按钮独立聚焦。实色列表；回到调用页使用设置页过渡 | **取代长底部选择层。** `ActionCatalog` 有 59 个固定 ID，末尾还有两种外部目标；用户需要跨组查找，也会进入配置页。保留“无”、当前选中项、点击选择和点齿轮配置的不同含义；子页返回恢复查询、滚动和原方向，取消不写入 |
| `action_app` 指定应用 | 全页**单选**应用目录，与例外页共用搜索、图标和加载组件；选中标记用 `COUIMarkPreference` 式行 | **增加搜索，保留单选。** 选择键是组件名，处理同名和已卸载目标。首次指定应用、只改配置、选择已有目标执行三条路径分别保留；“无法读取”有重试入口 |
| `action_shortcut` 指定快捷方式 | 全页按发布应用分组的展开列表；组头为图标、名称、数量和展开指示，子项为单选行 | **保留两级关系。** 搜索匹配发布者或快捷方式，展开到命中项。分别呈现加载、超时、无发布项、已停用、原选择失效、重试。保留组展开状态与滚动；无效项不提交 |
| `tools` 快速工具设置 | 小型设置页，编辑布局为主跳转，预览为次操作 | **保留设置与预览两个入口**，另从“面板与工具”目录进入。设置用实色；预览打开实际快速工具验证内容与触发边 |
| `ToolsSettingsActivity` 布局编辑 | SystemUI 快捷设置编辑式两区网格。已添加区三行四列，可用区显示图标与标签；顶部保存，恢复默认是草稿操作 | **采用编辑器结构。** 数量／上限、空位、添加／移除标记、拖动阴影和落位各有角色，不能借用工具实际“已开启”的强调色表示“已添加”。满 12 项说明原因；提供向前／后移动作为拖动替代。返回时对未保存草稿确认 |
| 工具编辑 → `ColorAppPickerPage` | 全页搜索式应用选择器，搜索栏固定，图标、名称、添加动作分行 | **共享应用目录，选择模式单独指定。** 排除已添加入口；保留查询、滚动和编辑草稿。IME 打开时结果仍可点击，取消返回相同格位；空目录与无搜索结果分别显示 |
| `widgets` 小组件设置 | 普通设置页；循环翻页是开关，“打开小组件”是明确预览入口，编辑说明就近显示 | **保留。** 页面不嵌入真实第三方组件复制预览。服务可用时打开浮层；服务未开启仍支持已有的手动预览路径 |
| `launcher` 快速启动设置 | 普通设置页；最近应用页开关、列数摘要、打开布局编辑的跳转行 | **分清浏览与编辑。** “编辑布局”直接进入编辑态；手势唤出默认浏览态。两者操作同一份布局。列数预览只需轻量网格示意 |
| `launcher_columns` 列数 | **短单选底部列表**，与快速启动编辑内使用同一组选项，当前值有明确选中标记 | **收回单独一页。** 2、3、4 三个常规值适合一次选择；只在已有 5 列时提供兼容值。旧页面恢复和原路返回应映射到同一设置项，不偷偷改列数 |
| `tasks` 任务切换器设置 | 普通设置页；“显示任务数量”是带当前值的单选行，实际选择用短底部列表，另有预览 | **收起整页重复数字。** 与浮层“数量”用同一列表和选中状态；8–13 与范围外已有值均能显示，取消保持原值 |
| `touchpad` 虚拟触控板设置 | 声音设置式连续滑条，慢／快、倍率当前值和预览入口各自明确 | **保留连续输入。** 0.5–3 倍速度可在正在使用的触控板上生效；预览中的移动面与设置滑条外观区分 |
| `navigation` 虚拟导航键设置 | 实色设置页，按键触控范围用滑条，顺序用可排序列表，左右边缘各有一个实机预览入口 | 保留 1–5 个按键和已有顺序。玻璃圆钮在点击范围内留出 6dp 的边距。行尾菜单可更换动作、前移、后移或移除 |
| `trial` 手势试划 | 实色设置页，识别结果放在单张卡片内，点「判定数据」展开距离、角度、时间和阈值 | 手势由屏幕边缘的实际触钮判定，结果行显示动作与配置来源。进入、退出试划或取消触摸时都要清理本次接触 |
| `overrides`、`override_picker`、`app_gestures` 按应用设置 | 已配置应用用跳转行，新增复用应用搜索列表，详情按触钮分组列出短滑和长滑 | 每个位置显示「继承」或「覆盖」和动作名称。动作目录保留「继承全局」和显式「无」，详情可试划该应用的映射 |
| `navigation_action` 选择导航动作 | 从设置进的全页分组单选目录，复用动作行；标题区分添加与替换 | **保留独立选择。** 只列导航允许的动作，排除其他位置已用项，保留正在替换的当前项。返回交还原行焦点，写入失败保留选择上下文 |
| `keyboard` 键盘快捷方式设置 | 普通说明页＋打开当前应用快捷键面板的入口 | **保留入口，精简说明。** 在面板上显示作用对象；设置页面避免让人误以为此处保存的是全局快捷键 |
| `permissions` 权限与后台运行 | 权限设置汇总页，必要条件与按需能力分组，各行独立显示状态、用途及下一步 | **重做状态层级。** 无障碍服务、后台电池、自启动、相机、通知、蓝牙、勿扰逐项说明。相机／通知／蓝牙当前合并请求，目标将用途与真实授权分别表达。无法可靠读取的 OEM 自启动状态只给入口；从授权页返回时重新查询 |
| `backup` 备份与恢复 | 数据管理设置页，导出、导入、迁移结果各一行；操作结果放在发起页 | **区分读写后果。** 导出直接交系统文件选择器；导入在读取后显示影响摘要再应用。取消、无权限、无效／过大文件、恢复失败分开反馈。报告存在才显示跳转；保留原配置格式与回滚语义 |
| `widget_migration` 小组件迁移结果 | 结果详情页，以结论开头，随后列成功、失败、待配置数量和具体 provider | **重排普通文本行。** 支持成功、部分、未迁入、目标已有内容、读取失败。需配置项显示应用和组件名称、可展开技术信息及现有配置入口；逐项原因以已有报告字段为准 |
| `about` 关于 | ColorOS 应用信息页；应用自身图标、完整名称、安装版本和简短介绍，静态实色布局 | **替换普通设置行。** 名称与版本构成识别信息，装饰区不给点击反馈；延续已确认的首屏字标和图标设计 |

## 运行中的工具与浮层

| 界面／部件 | 选定的风格与渲染 | 结构与交互决定 |
| --- | --- | --- |
