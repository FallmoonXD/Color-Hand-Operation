# 当前开发状态

更新：2026-11-08。版本 `0.3.16` / versionCode `19`，包名 `dev.edgeflow`。

## 0.3.16 之后的本地修复

设置页工具栏从系统设置读取 `coui_back_arrow`，按 24dp 绘制。边缘导航键按 SystemUI 图标的原始尺寸显示返回、主屏幕和最近任务，缺少系统资源时使用随包矢量。PKR110 的轮廓对照可运行 `tools/verify_navigation_glyphs.py`。

手势试划复用真实触钮和识别定时器。打开试划页后，命中结果交给页面显示，手势动作不会执行。设置页可按应用覆盖单个位置；显式「无」与继承全局分别存储。服务在按下时读取焦点应用，派发前重新核对。应用例外优先。快速启动文件夹以稳定 ID 绑定，改名后仍可滑入；删除后保留可重新选择的失效绑定。导入、导出支持这些新映射。

快速启动最近页按应用展示最多六个入口，「全部任务」打开按任务 ID 排列的完整列表。两处共享查询、短时结果和失败处理。系统页面动作集中在同一入口，仍可直接搜索。导航键改为触发侧纵向排列的一至五个玻璃按钮，按安全区和触钮宽度留出间距；顶部可上下拖动或点按关闭。两侧预览在导航键设置页。试划、前台切换、文件夹改名与滑选、任务去重及边缘按钮的本机记录在 `verification/gesture-features/`。

玻璃材质已移除面板和控件中央的矩形高光。浮窗给投影留出额外的绘制空间。在 PKR110 的快速工具上，底部阴影现在能连续淡到下层页面的底色。导航键的滑条控制点击范围，玻璃圆钮从各边内收 6dp；每个圆钮单独计算边缘高光，共用一次背景取景。实机对照在本地 `verification/glass-edge/`。

音量胶囊、快速工具、小组件、导航键和其他玻璃面板共用系统侧边音量条的提亮强度。亮度随下层画面调整，沿实际轮廓过渡，控件内部不会出现另一块矩形。PKR110 浅色模式下，CHO 音量按钮和系统音量条在相同浅灰底上取样均为 `#C9CACB`。本地对照在 `verification/title-glass-match/`。

快速工具只在控件之间的底板叠加 9.4% 黑色。音量区、轨道和按钮继续取原来的玻璃亮度。「面板与工具 → 快速工具 → 一次性动作使用强调色」默认关闭，开启后截屏、锁屏等动作按钮跟随系统强调色。Wi-Fi 等开关仍按实际状态着色。

手势箭头按 OHO+ 9.3.13 的曲线样式定位。左右两侧都以当前触点为准，往上移三个箭头图标尺寸，靠近上下边缘时限位。PKR110 上从同一高度直滑，触点在 y=1450 px，修复前箭头中心在 y=1450 px，修复后左右两侧都在 y≈1219 px。手势判定和面板弹出位置继续使用原始触点。

快速工具和小组件由无障碍浮层接收返回，打开面板时底下的 Activity 保持 resumed。有二级菜单时，第一次返回只关菜单。PKR110 上用两层测试页面分别试了系统返回键、导航栏返回和 CHO 的返回手势，两种面板共六种组合，底下的第二页都保留。小组件的系统绑定和提供方配置仍由 Activity 接收结果，取消新增会释放新 ID，取消已有组件的配置会保留原 ID。实机对照与检查结果在本地 `verification/wave-back-20261107-133312/`。

关闭应用使用实时焦点窗口，Root 授权完成后再次确认，最后核对顶层任务、用户和锁屏状态。两种屏幕放大功能共用 API 33 兼容实现。旧浮点触钮透明度在编辑和备份时转换为整数百分比。亮度请求支持取消和超时，快捷键新名称限制为 256 字符，旧超长名称可以完整导出和恢复。

已在 PKR110 安装修复构建并测试快速工具/手势的有效与失效目标、系统放大、放大镜倍率、快捷键输入和亮度写入。23 组离线验证通过；API 33 使用缺少 API 34 激活方法的接口替身检查链接。设备测试助手会按单选行选择“返回”动作并等待读回，避免与页眉或系统返回键混淆。测试细节保存在本地 `verification/bugfix-ui-20261107-110400/`。

## 工程结构

这是独立 Android 工程。主要入口是 `MainActivity`、`GestureService`、`GestureRecognizer` 和 `ActionExecutor`；设置控件、主题、浮层材质及小组件在 `replica/`。

构建和运行不读取外部 `analysis/`，也不需要安装参考应用。改名称或外观时保留包名、配置格式和小组件 host ID，避免影响已有数据。公开版本使用 `X.Y.Z`，Release 标题使用 `Color Hand Operation X.Y.Z`。

## 当前外观

- COUI 试用版把七类工具设置收进首页「面板与工具」，触钮宽度、大小、位置和颜色移到「触钮范围」。手势方向打开完整的动作目录，支持搜索；齿轮返回时保留过滤结果和位置。应用例外、指定应用和工具编辑共用可回收的应用列表。
- 快速启动的手势入口打开浏览态，设置入口打开编辑态；小组件浏览有独立页面菜单，编辑栏放在底部，移动／缩放也可通过菜单操作。任务切换器使用真实预览卡，服务内的选择窗使用自身的窗口材质。
- 配置文件通过校验后，先显示导入范围，点「导入」才应用。权限页逐项显示用途和实际授权状态。试用版验证记录在本地 `verification/coui-trial-20261107/`。
- 首页标题的 `Color` 取自 ColorOS 17 官网字标。首页和二级页共用 52dp 工具栏和 18sp 标题样式，更多和返回使用同尺寸的圆形按钮。「已开启」下方的两句说明随宽度换行。短页面从选项或空白处上滑都能回弹，静止渐变与滚动模糊分别绘制。实机回归入口为 `tools/verify_short_settings_header.py`。[标题与上滑遮罩](settings-title-motion.md)
- 动作目录使用实色设置页。更多菜单、颜色面板和确认框使用各自窗口的材质。关闭模糊或遇到缺少对应接口的设备时显示主题底色。实现位置与本机对照见[渲染方案](coloros17-rendering-plan.md)。
- 首页更多及共用的锚定菜单分别给内容和窗口模糊背景设置入退场透明度。修复前录屏可见背景先闪出来，再变淡；修复后从首帧连续淡入。对照与复测方法见[弹出菜单](settings-popup.md#opening-and-closing)。
- 设置页沿用 ColorOS Settings 的字体、行距、卡片、开关、菜单和过渡。
- 快速工具、音量和小组件面板的材质已经实机调过；没有具体问题时，不重调捕获、shader、混色和光学参数。
- 手势波形固定为 OHO+ 风格方向箭头，不再提供自定义波形入口。
- 彩色图标以 `design/user-layered/CHO-Color-Layered.clip` 为准：橙紫渐变背景、Overlay 混合前景、薄亮边和渐隐箭头。整只手和手臂连续，不加掌心、袖口或指节细节。
- MD3 保留手机、填充屏幕、完整手部三个色阶。只改彩色图标时，不重新生成 MD3。

新图标的导出方式和设备像素对比见[图标记录](user-layered-icon-validation.md)。0.3.16 在此基础上更新版本号和仓库文档，手势及面板逻辑未变。改图标后仍要打开图片，检查小尺寸和 Android 原生渲染。

## 构建与设备操作

JDK 21、Gradle wrapper 9.5.1、AGP 9.2.1、SDK platform 35 / build-tools 36.0.0。普通 APK 构建不需要 Python。图标生成工具使用 Pillow、resvg_py；旧矢量轮廓处理另需 skia-pathops。

ADB 只有一台已授权设备时自动选择，多台设备必须设置 `EDGEFLOW_SERIAL`。部署保留其他无障碍服务，旧视觉测试版迁移需要显式选项。

手机 UI 树使用独立 probe，避免普通 `uiautomator dump` 干扰无障碍服务。只读 probe 偶发被系统结束时可以重试；写入动作要先读回结果，再决定是否重试。测试前记录需要恢复的亮度模式、音量、配置和临时状态。

涉及实机 UI 时先读取当前亮度、充电保持唤醒和超时设置，保持已解锁屏幕直到实机步骤完成。结束后恢复临时修改的值，按当次情况息屏，避免长时间停留在静止画面。保留机主已设置的充电常亮和低亮度。

## 功能与兼容

亮度仅在读取到可信范围后允许调整。原生材质有服务检查、授权/绑定失败处理和有限重连。Athena 脚本只匹配已经记录的机型及完整固件。

此前在 PKR110 上测试过 2..4095 亮度范围、写入后恢复、快速工具和小组件原生材质、音量手势及配置保留。部署逻辑、亮度和材质恢复策略的离线检查分别为 24、49、15 项，具体对应 0.3.15 的记录。历史测试次数不累计成新版本回归结果。

其他机型和固件、无 Root、工作资料/副用户、折叠屏、跨签名升级及长期后台表现还需要测试。详细功能差异见[功能说明](feature-status.md)和[兼容说明](compatibility.md)。
