# 开发接续状态

更新：2026-11-06；当前版本 `0.3.15-neutral-glass` / 18，应用包名 `dev.edgeflow`。

## 项目边界

本目录是独立 Android 工程。最初的 gulugulu、APK 解包、采样和旧视觉测试在工程外完成；构建和运行不读取外部 `analysis` 目录。`replica` 是迁入的自有原生 UI 模块名称，不表示运行旧 APK。

主要入口：`dev/edgeflow/MainActivity.java`、`GestureService.java`、手势引擎与 `ActionExecutor.java`；浮层、系统主题、原生材质和小组件在 `replica/` 中。配置包名、已有用户数据与小组件 host ID 不要因重命名或视觉调整而改变。

## 已确认的设计约束

- 设置页面学习 ColorOS Settings 的字体、行距、卡片、开关、菜单与过渡。自有组件不回退成可见的 AOSP 菜单风格。
- 快速工具、音量和小组件浮层的材质经过多轮实机确认。没有新的具体反馈时不要重调其明暗、混色和光学参数。
- 手势波形固定 OHO+ 风格，使用方向箭头，已删除自定义波形调节入口。
- 应用图标保留原 OHO 手机/手轮廓、紫橙背景和渐隐箭头。最新前景为中性白灰、柔和薄亮边；整只手和手臂连续，不能再增加袖口分色、掌心结构或手指塑形。
- MD3 只有手机、填充屏幕和整只手三个色阶。不得用多个局部 alpha 叠出额外手部边界。
- 图标调整必须打开图片亲自看，并核对小尺寸/原生渲染；源码与数值检查不能代替视觉判断。

## 本版公开准备

移除个人设备默认值。ADB 只有一个已授权设备时自动选择，多设备要求 `EDGEFLOW_SERIAL`。默认部署保留其他无障碍服务；旧视觉测试版迁移是显式选项。

亮度改为可信范围与能力探测；未知范围不写入。原生材质增加服务/Root/绑定失败收敛及有限恢复。Athena 脚本限制已验证的机型和完整固件。没有改变已确认材质的捕获、shader、混色和光学参数。

## 验证与构建

JDK 21；Gradle wrapper 9.5.1；AGP 9.2.1；SDK platform35、build-tools36。普通 APK 构建不需要 Python。图标生成依赖 Pillow/resvg_py/skia-pathops，仅在开发机使用。

本版新增针对性检查：部署逻辑24项、亮度49项、原生材质恢复策略15项；整包离线构建通过。实机已确认当前设备 2..4095 亮度范围、raw 调整值写入后恢复、快速工具和小组件正常原生材质连接、音量手势与配置保留。图标原生渲染中，手指/后手/手掌/手腕/手臂为同一全不透明色阶。

历史 UI 与功能验收在其他文档中；不同轮次的断言不要相加后宣称全部为当前版本重新实测。个人 `verification/` 数据不提交到仓库。

设备操作采用 ADB 和独立 UI 树探针，避免普通 `uiautomator dump` 抑制正在使用的无障碍服务。只读 probe 偶发被 OEM 杀死时可重试；写入动作先读回结果再决定。验证期间保存必要原值，结束恢复亮度模式、音量、配置和暂时修改的状态。用户要求最终手机息屏。
