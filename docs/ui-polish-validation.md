# 0.3.4 · 设置页与交互修正

2026-11-05 至 11-06，OnePlus PKR110 / ColorOS 17。版本 `0.3.4-ui-polish`，versionCode 7，包名继续为 `dev.edgeflow`。

## 改动

- 图标重绘为修长手机、简化浅色手部、单条带圆头的侧滑轨迹，配色改为钴蓝至蓝紫。保留“单手操作手机”的构图含义，同时改变了轮廓、标记和配色；来源说明见设计 JSON。普通、自适应、单色和通知版本同步更新。
- 首页总开关仅更新文案和下方控件状态；左右触钮保留原控件。弹簧在业务回调前开始计时，重复赋值不重启动画，逐帧绘制不再反复读取主题资源。
- 服务将立即重载和偏好通知合并，日常开关/位置/颜色更新复用两块波形窗口和六个窄触摸窗口。关闭的触钮保持 GONE，额外触钮的重叠优先级不变。连接、屏幕配置改变和权限清理仍执行原有必要路径。详见 [窗口更新机制](gesture-window-updates.md)。
- 添加/移除仅增删对应卡片并执行布局过渡，保留首页、已有控件和滚动状态。次级页面长滑、对齐开关也取消了整页重建。
- 更多按钮使用本机 Settings 的真实三点矢量，跟随标题展开/收起。更多及移除菜单按按钮定位；点击后先完成退出和窗口移除，再导航或更改列表。详见 [菜单资源与适配](settings-popup.md)。
- 设置行统一最小 64dp、上下 10dp，参数区域统一横向内边距和 500 字重标题；自动添加缩进分隔线并避免与已有分隔线重复。多行说明按内容增长，不强行裁成相同高度。
- 后台主题通知标记待刷新，返回首页时更新整套主题；平常返回仍保留现有控件。快速工具编辑器统一字体留白/分组标题，并按实际两行字体高度为大字号名称扩展网格。

## 验证

离线 APK 构建与安装成功。控件/调度 89 项、服务窗口更新 33 项、手势与实际输入方法 280 项、菜单几何 125 项 JVM 验证通过。模型测试不会代替设备上的窗口与帧时间检查。

实机验证包括：

- 总开关和左右开关往返切换，控件 node-hash 与窗口 ID 保持一致；8 个手势窗口身份未变。
- 添加到三对、上限禁用、取消移除、逐对移除，主开关和原左右控件保持同一实例，动作/位置保留。
- 更多按钮与标题中心对齐，菜单返回/关于导航正常；移除菜单按按钮向上展开，退出后才改变布局。
- 次级长滑开关保持同一控件；纵向经过滑块不改值，点击滑块与拖动取消保持同页，长滑仍同时要求距离与时间。
- 后台修改材质设置后，在同一进程、同一 Activity 窗口中返回首页，标题/页面按主题通知重新构建；系统设置随后恢复原值。
- 添加过程录屏逐帧查看，标题与已有卡片保持稳定，没有整页空白帧。主开关录屏能看到中间位置与颜色过渡。
- 快速工具编辑器在系统字号 1.6 下实测，网格行从 309px 增至 341px，长名称完整显示两行；“保存”按实际字宽预留空间并保持单行。字号与工具布局均恢复。

本轮录屏与切换期间，`gfxinfo` 合计 380 帧、1 帧 jank；主 Activity 为 376 帧、1 帧 jank，P95 6ms、P99 9ms。这是当前手机和本次操作的观测值，不是所有场景的性能保证。

设备测试记录位于本地 `verification/ui-polish-validation.json`、`ui-polish-theme-motion.json`、`polish-switch-framestats.txt` 及 `polish-*.png/mp4`。所有测试更改均恢复，发布前再次逐项比较四份偏好与本轮基线，并核对安装 APK 哈希。
