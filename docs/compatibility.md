# 兼容与已知问题

目前主要测试设备是 **一加 PKR110，ColorOS 17 / Android 17，Root，主用户**。应用最低支持 Android 13 安装，其他系统上的功能是否可用还要看权限和厂商接口。

## 哪些地方需要 Root

无障碍服务负责边缘手势、返回、最近任务等基础操作。设置页、工具面板和小组件由应用自己绘制。

ColorOS 原生模糊材质依赖 `com.oplus.blur` 和匹配的隐藏接口，需要 Root。单手模式、系统侧边栏、录屏、部分系统开关和任务快照也有系统限制。

没有模糊服务、Root 被拒绝或绑定超时时，面板会使用普通材质，当前进程不会反复弹授权。想重新尝试可以重启应用；连接成功后意外断开，最多自动恢复两次。

## 常见情况

| 情况 | 说明 |
| --- | --- |
| 面板没有原生模糊效果 | 检查 Root 授权、系统质感视效和省电模式；系统版本不同也可能缺少接口 |
| 亮度滑条不能拖动 | 应用没有读到可信的亮度范围，因此停用调整；不会直接套用其他手机的数值 |
| 某个动作无反应或提示不可用 | 先确认对应权限，再检查 ColorOS 版本；同厂商的不同固件也可能换接口 |
| 后台被清理后手势消失 | 检查无障碍、自启动和电池限制。长期后台表现还需要更多测试 |
| 小组件需要重新设置 | 绑定 ID 不能跨应用直接沿用，需要走系统绑定或小组件自己的配置页 |
| 覆盖安装失败 | 检查安装包签名是否一致；自行编译的包通常与发布包签名不同 |

亮度范围依次从系统设置、OplusPowerManager 和系统属性读取。只有明确检测到 Oplus 多位亮度支持时，才使用对应的 raw 调整值。

`tools/keepalive.sh` 是可选的开发调试脚本，只匹配记录过的机型和完整固件指纹。普通安装不会部署它，不建议为绕过检查而修改白名单。

## 尚未充分测试

其他 ColorOS 机型、旧版系统、无 Root、折叠屏/平板、工作资料、副用户，以及长时间待机和耗电。字体、主题、窗口大小和系统更新也可能影响显示。

## 反馈问题

到 [Issues](https://github.com/FallmoonXD/Color-Hand-Operation/issues) 留下这些信息即可：

- 机型和 ColorOS / Android 版本。
- 是否 Root，使用哪个 Root 管理器。
- 出问题的动作、复现步骤、预期结果和实际结果。
- 有相关报错时，附上对应的几行日志。

日志和截图里记得遮掉账号、令牌、序列号等私人信息，不用上传完整配置或整个日志文件。
