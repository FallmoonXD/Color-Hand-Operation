# 0.3.1 交互修正

2026-11-05，当前一加 PKR110，版本 `0.3.1-interaction-fix`（4）。本轮修复用户报告的三项问题；手势映射、触控区域原数值、面板布局与材质参数保留。

## 标题

此前是两个标题交叉淡入，且大标题受滚动容器裁切。现在保留原字号和布局端点，只绘制一份标题，随滚动连续改变位置、字号和字重，采用本机 Settings 的 COUIEase 曲线。滚回顶部沿同一路径恢复，不另加延时或独立弹簧。

实际录屏确认展开、收起及反向变化连续；无障碍树只有一个标题，更多菜单仍可点击。精确系统来源和保留折叠标题所做的适配见 `settings-title-motion.md`。

## 触控区域

根因之一是 `geometrySlider` 每次提交调用整页 `render()`，再异步恢复滚动位置。改为同组视图原位更新，宽度/大小/位置互相夹限后的读数同步，取消仍不保存。另一个根因是滑条起点被强制排除在父页拦截之外；现在按触摸阈值后的主方向分流：竖向归页面、横向归滑条，静止点击由 SeekBar 正常处理。已确认方向后不在同一次拖动中反复改变所有者。

保留原生 ScrollView 的惯性首触拦截，触碰移动页面先停止滚动。滑条的按压放大在实际开始调节时发生，竖向翻页不会先闪出滑块按压材质。边界回弹中的首触同样由父页接管。

实机验证：

- 从宽度条上开始斜向竖滑，页面确实滚动，全部配置逐项不变。
- 点击当前值、点击新值后，滑条的无障碍节点身份、窗口和屏幕坐标均保持，未重建页面。
- 新值同时应用于已联动的左右区域；随后通过同一滑条恢复原精确值。
- 横向拖动正常显示两个实际边缘预览；按住时不写配置，CANCEL 后数值与原来完全一致，预览窗口移除。
- 通过同一输入进程在底边释放后 16ms 点击回弹中的滑条，配置不变。测试避免在中间调用耗时 UI 查询，以免手势已经等到回弹结束，误把正常静止点击当成“停止回弹”。

## 长滑

原 `finish()` 只检查是否达到长滑距离，松手路径绕过了 `long_delay_ms`。现在从 **ACTION_DOWN** 开始计时，当前距离达标且持续时间达标才识别为长滑。提前松手仍按对应短滑处理。

“快捷操作”只决定达到两个条件后立即执行，或等待松手执行；两种模式始终显示持续时间。时间判断使用事件自身的 `eventTime`，避免主线程排队把短手势误算成长手势；定时器使用同一绝对截止时间。撤回距离、取消、第二指或服务窗口退出都会取消待执行任务。旧配置 `long_immediate` 继续等价于有效 0ms，设置新持续时间会清除此兼容标记。

实机在原 300ms 设置下，左右两侧用 80ms 划过长滑距离并松手，均只执行音量短滑，没有误开小组件；650ms 长滑仍正常打开小组件。关闭快捷操作后，达到条件且保持手指按住时不执行，抬手后正常打开。

这次统一时间门槛遵循用户的明确要求。OHO+ 原版关闭快捷操作时存在仅按距离的松手分支，本版有意不再保留该绕过；源码证据与边界测试见 `gesture-validation.md`。
