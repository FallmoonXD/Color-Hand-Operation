# ColorOS UI 0.3.0 实现与验证

2026-11-05，一加 PKR110 / ColorOS 17 / Android 17，包名 `dev.edgeflow`，版本 `0.3.0-coloros-ui`（3）。本轮保留 OHO+ 菜单结构、既有手势动作和已验收的浮层材质参数。

## 实现

- 设置页从本机 `com.android.settings` 的资源表读取主色、正文、摘要、页面和卡片颜色，按当前 COUI 配色模式应用系统拥有的 overlay。监听系统配色、夜间模式、字体配置、模糊与流光轮廓开关；不嵌入或运行 Settings APK 的 Java 类。
- 大标题、二级栏、行标题与摘要按 Settings 资源继承链设置字号和字重，字体仍由系统 Typeface 提供。共享开关、滑条、单选与复选控件使用已提取的 COUI 尺寸、图形和弹簧参数，保留 Android 的触摸、键盘和无障碍语义。
- 触摸宽度、大小、位置增加用途说明、手机示意和当前数值。拖动时真实屏幕边缘同步高亮；左右对齐时显示两侧。抬手提交，取消或页面销毁不提交；预览不改变实际触摸窗口或长期可见度。
- 圆点是触钮组的区域标识，与预览颜色对应，不是实际触钮颜色。改为半透明，并提供长按说明和无障碍描述。
- 设置页与快速工具编辑页增加来源明确的 350ms 页面过渡；滚动边缘使用阻尼回弹。退出中的页面只拦截输入，不改变控件启用状态，避免蓝色开关在转场开始时闪成灰色。
- 快速工具编辑、操作选择、应用搜索、小组件菜单和输入/确认弹窗使用共享样式。补齐输入法、取消、生命周期释放及主题刷新；系统自己拥有的权限和文件选择器继续交由系统显示。
- 已接入的 OEM 背景捕获管线跟随质感视效设置：关模糊立即停止客户端捕获，使用系统音量面板的可读不透明回退；关流光轮廓只停边缘光学层，保留背景模糊。恢复后使用原先已验收的混色、边缘与阴影参数。

## 实机验收

| 项目 | 结果与证据 |
| --- | --- |
| 系统蓝色 → 绿色 → 原配色 | 设置资源实际返回 `#FF0080FF` → `#FF00BD13`；开关/强调色随之变化。原 MaterialYou 完整 JSON 已恢复；COUI 低 32 位相同，高 32 位仅是系统刷新序号。 |
| 亮色/深色 | 编辑器在两种模式显示正常，未保存的 11 项草稿跨配置重建保留，放弃后恢复原 12 项文件。 |
| 二级页面 Insets | 标题位于状态栏下方，修复初次切页时顶部重叠。 |
| 触摸预览 | 实际出现左右两个窄预览窗口；拖动中配置未写入，CANCEL 后配置逐项相同且预览窗口消失。主题刷新打断拖动同样不提交。 |
| 对话框与输入 | 操作列表图标居中，应用搜索弹出真实输入法，取消/放弃不改变布局。 |
| 实时材质开关 | 快速工具保持打开时分别关闭边缘和模糊；原生状态 `active=1` 降到 `active=0`，恢复可再次捕获。白色文字/滑条在不透明回退上仍可读。 |
| 小组件 | 支付宝组件完整显示，页面菜单可打开，布局与宿主 ID 未改。 |
| 音量 | 左右短滑加减均执行，点击外部按既有 500ms 出场动画收起，恢复原音量。 |
| 页面动画 | 录屏逐帧检查前进与返回；关闭系统动画后仍可导航。修复旧页控件在退出动画时被置为禁用色。 |
| 字体缩放 | 临时切换 1.15 倍，正文和行布局跟随变化，再恢复 1.0。 |
| 用户数据 | `edgeflow`、`edgeflow_launcher`、`replica_widgets` 与快速工具文件均逐项/逐字节核对；手势映射、支付宝绑定与原布局保留。 |

设备证据位于本机 `verification/coloros-*`；可复验脚本为 `tools/verify_coloros_ui.py`、`tools/verify_coloros_motion.py`。它们使用保留其他无障碍服务的独立探针，不使用会抑制服务的普通 uiautomator dump。`--panels` 可仅复验材质和小组件阶段。

构建为离线 Gradle `assembleDebug`。配置验证 111 项、控件物理 55 项、滑条取消 16 项、设置回弹 51 项、材质生命周期/参数/回退 88 项，共 321 项通过。单元检查并不冒充 GPU 或实机触摸验收。

## 边界

这是一套读取系统资源、复现 COUI 参数并使用现有原生背景捕获接口的独立实现，未把整个专有 COUI 控件库嵌入应用。OEM 私有快甩、帧率调度、所有主题商店皮肤和三星独有服务不宣称完全等价。主题包路径权限受限时状态会明确记录；当前设备读取为 `no-settings-package-skin`。系统主题绿色/蓝色、深色模式、字体缩放与两个质感视效开关已经实际验证；未安装额外主题商店皮肤来测试。

详细来源与行为边界见 `coloros-controls.md`、`settings-page-interaction.md`、`material-policy.md`、`coloros-theme-audit.md`。已有完整 OHO+ 功能范围仍见 `feature-status.md`，这轮完成的是用户提出的界面与交互统一。
