# 0.3.5 · 图标、说明与操作选择面板

2026-11-06，OnePlus PKR110 / ColorOS 17。版本 `0.3.5-design-refinement`，versionCode 8，包名仍为 `dev.edgeflow`。

## 改动

- 图标重绘握持结构：前方拇指与后方握指分层，掌根连续，移除掌心硬三角色块。采用珊瑚至莓粉背景、冰青玻璃机身、薄高光和局部反光；手部和袖口不透明。普通、单色、通知资源一起更新，出处和设计取舍见 [图标记录](glass-icon-validation.md)。
- MD3 单色版改为一条完全不透明的路径，手机、滑动标记和手部用负形分隔。没有半透明轮廓叠加，边缘仍保留正常抗锯齿。
- 首页说明合并为一段，参数说明直接描述测量单位、比例、距离与时间条件。统一摘要和说明的行高，设置行保持最小 64dp；多行内容自然增高，不强制裁切。
- 振动强度显示 0–100%，底部单独说明“0：使用系统触觉反馈”。保存和调节仍采用原始 0–255 数值，非零极低强度至少显示 1%，避免与系统反馈的 0 值混淆。
- 手势操作及“启动指定应用”的选择界面改为 ColorOS Settings 风格底部面板，固定标题、关闭与取消区域，内容独立滚动。收起并移除窗口后才执行选择或导航，后台切换取消待执行操作。组件来源及具体适配边界见 [面板说明](settings-action-sheet.md)。
- 应用例外显示应用实际图标，后台读取名称、缩放到 40dp 后再绑定，按包名去重。启动应用选择按组件去重，保留应用别名入口。过期异步结果不会更新离开的页面。

## 实机验证

`tools/verify_design_refinement.py` 验证通过：

- 首页左右触钮均为 267px 高，高级设置与手势设置均为 224px 高。前者含两行摘要、后者一行；相同结构行等高。
- 关闭按钮、返回键和点击面板外部均能收起，不修改映射。
- 快速工具、小组件、快速启动、任务切换器、虚拟触控板、导航键及键盘快捷方式七个设置入口均能返回操作选择器，未改变动作绑定。
- 应用选择列表加载真实图标，取消保留原绑定；选择当前已选动作保持原配置。
- 应用例外加载 112 个可启动应用。检查了图标、名称、勾选框和滚动布局，没有更改例外勾选状态。
- 振动中值显示 50%，原始幅度仍在约 128 的位置，调节前后滑条保持同一实例。测试后恢复原始 0 值。
- 四份偏好存储与本轮开始时逐项相同，快速工具布局文件 SHA-256 不变。

首轮实机打开面板发现系统栏控制器读取早于 DecorView 建立的问题；已增加窗口内容存在检查，后续创建完成的刷新再设置系统栏。修复后重新安装并完整执行上述流程。另修正新组件关闭按钮的中文无障碍标签编码。

`tools/android/probe/IconRender.java` 使用设备框架直接绘制已安装 APK 的 AdaptiveIconDrawable 与 monochrome 层。新版单色图标在剔除三像素边缘后，16,040 个内部像素均为 alpha 255；未发现内部透明叠色。实际普通/单色图像和 72px、44px 预览均已查看。本项验证资源渲染，不代替所有第三方启动器的主题实现。

本地验证：面板安全区域布局 363 项、既有控件/取消/回调验证 89 项、振动显示 9 项（覆盖全部 256 个存储幅度）通过；离线 APK 构建通过。

`tools/verify_design_refinement_bounds.py` 另外验证了拖动标题区域关闭，以及切换到系统设置后返回时不残留选择面板、不执行旧选择。在系统字号 1.6 下检查首页、操作面板和应用例外，关闭与取消按钮均在可用区域内；随后恢复系统字号并确认偏好未变。后台验证等待外部 Activity 完成切换，不将立即 Home/返回所取消的系统转场当作已完成的后台生命周期。

本机证据位于 `verification/design-refinement-validation.json`、`design-refinement-installed-icon.json` 和 `refinement-*.png`。这些文件不参与应用运行。
