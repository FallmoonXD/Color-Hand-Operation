# 0.3.8 角度与触控区域验收

2026-11-06，当前一加 PKR110 / ColorOS 17，1264×2780、density 3.5。版本 `0.3.8-angle-editor`，versionCode 11。

## 修改

- 无小字的普通选项最小行高由 64dp 改为 56dp；有说明的选项保留 64dp 最小高度，多行说明随内容增高。
- 设置页滑条的实际轨道与端点文字间距约 4dp，保留 44dp 触控高度以及纵向滚页判定。共享浮层滑条的绘制不变。
- 参数读数显示整数，保存和计算仍使用原精度。速度倍率改以整数百分比表示，避免把不同的小数倍率显示为相同整数。
- 短滑、长滑分别使用四边界可拖动角度图。方向引导箭头固定；识别边界、扇区与整数角度实时变化。松手提交所拖动的边界，取消恢复；左右按钮只改变查看侧。镜像按钮有独立列，大字号时不覆盖图形文字。
- 触控区域统一使用忽略临时可见性的状态栏、导航栏及挖孔安全边距。100% 位于系统栏之间，真实手势窗口和半透明预览共用同一矩形；键盘不是百分比的分母。

## 配置兼容

新增独立坐标版本 `handle_geometry_version=2`。旧全屏百分比先换算为物理端点，再转换为安全区域百分比；侵入系统栏的端点裁至可用边界。六个触钮一起迁移，包括尚未启用的触钮。导入旧配置时同样转换，已是版本 2 的数据不重复转换。

本机原左右窗口为 `[0,139]-[71,2642]` 与 `[1193,139]-[1264,2642]`，现在为 `[0,140]-[71,2626]` 与 `[1193,140]-[1264,2626]`。原宽度保留；大小读数对应新的 100% 可用区域。动作、颜色、开关、另外三份配置存储和快速工具布局均与迁移前一致。调试产生的参数修改已恢复至迁移后的基线。

## 验证证据

- `verification/safe-angle-migration-validation.json`：坐标迁移及非几何配置保留。
- `verification/safe-angle-ui-validation.json`：实测单行/双行最小行高为 196/224px；文字到轨道 14px；100% 实际输入窗口和预览均为 y=140–2626；滑条纵向滚页不修改范围；图形取消不写配置，松手只提交对应边界，镜像和空白处滚页不改角度。
- `verification/safe-angle-environment-validation.json`：大字号、旋转与测试设置还原，实际结果以该文件为准。
- `verification/safe-angle-final-verification.json`：最终安装包、配置与设备状态核对。

几何、配置迁移/导入、服务窗口更新及手势识别共 2152 项断言；角度图几何与拖动状态 161 项；整数显示 22 项。生产 Java 编译和 debug APK 构建通过。真机触摸与窗口测量独立于这些 JVM 验证。

实现依据与边界分别记录在 [安全区域](handle-safe-area-validation.md)、[间距与数值](settings-spacing-integers.md)、[OHO+ 角度原理](oho-haptics-angles.md)。其他手机、折叠屏和其他导航模式尚未进行同等实机验证。
