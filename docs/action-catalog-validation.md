# 操作目录和动作目标验证

`ActionCatalog` 是展示目录，与 `ActionExecutor.IDS/TITLES` 的执行注册分离。0.3.11 删除重复的可选入口，同时保留执行注册顺序和已保存的动作 ID；当前页面返回语义与设备结果见 [页面连续性记录](continuous-pages-validation.md)。

## 展示契约

`ActionCatalog.groups()` 提供“无、导航、屏幕、音量与媒体、系统开关与设置、需要设置”六组。第一组仅含 `none` 且不显示组标题。最后一组是有本应用配置页的七个动作：快速工具、小组件、快速启动、任务切换器、虚拟触控板、导航键面板、键盘快捷方式。Main 在此组后追加启动指定应用、应用快捷方式，两者使用独立二级页。

`destination(id)` 只描述本应用的动作配置页。系统设置、热点设置、护眼设置、无障碍设置是直接打开系统页面的动作，不应被当成需要预先配置目标的动作。所有目录方法返回独立数组，不会让一个列表的临时排序影响另一个列表。

## 已执行验证

在 `standalone` 目录运行：

```powershell
./validation/action-catalog/run.ps1
```

39 项断言通过。脚本直接编译生产 `ActionCatalog`、`ActionTarget`、`ShortcutEntry`，从生产 `ActionExecutor.java` 读取真实注册 ID 与名称，而不是复制一份固定注册表。Android SharedPreferences 由最小内存边界代理提供；ComponentName 使用既有配置测试的解析替身，没有执行 Android 窗口或设备操作。

覆盖内容：

- 60 个执行注册动作与名称数量一致；59 个可选动作无遗漏、重复，仅移除明确退役的 `app_launcher`；配置动作连续置底，`none` 保持首位。
- 七个配置目的地在 Main 的真实页面分派中存在；目录 API 一致，外部修改返回数组不污染之后调用。
- 读取目标不会写入；只配置应用或快捷方式时，保留当前不同类型的已选动作；当前已选同类动作则跟随新目标更新。
- 切换普通动作、应用、快捷方式后，两个外部目标分别保留；其他手势槽不受影响。
- 错误目标类型在写入前被拒绝。

这些断言检查数据层的选择和配置逻辑；返回、旋转和窗口退出另做设备测试。

## 0.3.9 历史审查与设备验证点

以下记录 0.3.9 的流程，0.3.10/0.3.11 已按用户后续要求改为返回原选择页。

旧返回重弹来自两类显式路径：`chooserReturnKey/chooserReturnScreen` 在 render 中重开选择页；以及外部动作配置完成或取消后直接调用 `chooseAction`。Main 本轮已移除前者与这些后续重开调用。新设置页应沿页面历史返回原手势页。

仍应在最终 APK 上检查下列交互，而不是只看数据层断言：

1. 快速工具等七个配置入口，改值后系统返回、页眉返回均只回手势页；取消操作列表不改变动作。
2. 已选“返回”时进入应用/快捷方式右侧设置，保存目标后仍选择“返回”；左侧选择外部动作后使用刚保存的目标。
3. 已选应用时更改应用目标，已选快捷方式时更改快捷方式目标，立即更新对应动作；切到另一类动作再切回，目标仍保留。
4. 二级页加载中返回、切后台、主题重建，旧查询不能再展示列表、写入动作或关闭新页面；重新打开可重新加载。
5. 只有真正快捷方式入口的应用出现在快捷方式页；展开返回不选择条目；不可用入口保持禁用，不改为启动应用。
6. 应用卸载或快捷方式消失后，取消页面不清空既有配置；选中的目标与可用性提示保持一致。

本轮没有操作手机，也没有独立部署 APK。目录编译和上述检查不能代替最终页面退场与设备返回验证。

## 删除重复的应用启动器选项

`app_launcher` 不再出现在手势操作目录、导航键候选列表、快速启动的“选择系统动作”列表。其他动作的既有顺序未改变，`quick_launcher` 快速启动保留。快速工具使用独立的 `ToolsConfig.TITLES`，原本就没有该选项，无需修改。

执行层注册 ID、名称、分派分支均保留，因此既有手势、导航键、快速启动根目录/文件夹里的旧入口继续可用。导航的候选集合与已存配置校验分离，避免因菜单删除而将旧导航重置为默认值。快速启动保存其他候选项时也不会移除未出现在候选列表里的旧入口。没有迁移或重写用户配置。

配置验证额外加入 6 项旧入口兼容断言，配置套件总计 217 项通过：验证旧手势和导航读取不回退、执行 ID/名称保留、导航候选删除且名称仍对应、导入导出后旧手势/导航/快速启动根目录与文件夹内容保留。配置套件还完成了全量生产 Java 编译；未在设备执行旧应用启动器动作。
