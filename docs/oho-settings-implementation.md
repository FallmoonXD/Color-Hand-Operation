# OHO 设置页重构记录

2026-11-05。根据 OHO+ 9.3.13.0 的 layout 和 Java 整理页面结构，见[原版设置结构](oho-settings-layout-audit.md)。

## 已实现导航

- 首页：总开关、两段说明、同组左右触钮、按需第二/第三对、添加/移除按钮、高级设置、手势设置；仅单对且对齐时在首页显示触摸宽度/大小/位置/触钮颜色。关闭总开关会禁用并淡化主控制区。
- 每侧页：短滑直线/对角线上/对角线下，带真实启停开关的长滑组，对齐触钮。长滑关闭隐藏其三行并保留原动作。多对或独立几何时在此显示尺寸/位置/颜色，额外触钮不显示触摸宽度。
- 关闭的触钮整行点击先启用；已开启再进入配置。颜色点只作指示，不另设隐形操作。
- 动作选择：单选按钮、动作名称、按功能显示设置齿轮。齿轮打开真正参数页；返回参数页时重新显示原动作选择器。
- 高级设置：应用例外及已实现的场景隐藏。用户明确移除的动画调参未重新添加。
- 手势设置：短滑快捷操作/角度/距离；主侧至少一个开启长滑时显示长滑设置；长滑持续时间仅快捷操作开启时显示。振动使用实际现有反馈和强度。
- 更多菜单：关于、恢复默认设置、备份与恢复、权限与后台运行。恢复默认会确认，只重置主设置，保留面板布局和小组件。

## 功能配置

| 动作设置入口 | 已有真实配置/编辑能力 |
| --- | --- |
| 快速工具 | 编辑三排按钮、预览 |
| 小组件 | 循环翻页、打开组件编辑面板 |
| 快速启动 | 最近应用页、2/3/4列、编辑应用/快捷方式/文件夹 |
| 任务切换器 | 8至13个任务、预览 |
| 虚拟触控板 | 移动速度、预览 |
| 导航键面板 | 方向、大小、1至5键排序/动作、预览 |
| 键盘快捷方式 | 按应用编辑的使用说明和真实面板入口 |

旧5列和旧5/20/30个任务设置仍可读取、显示及导出导入，没有在打开页面时重写。新添加的触钮对初始保留既有关闭状态和既有动作，不覆盖用户原12个动作；移除只停用并隐藏，保留配置供重新添加。

几何控件显示引擎实际使用值。旧中心/高度覆盖只在用户修改几何时迁移，先保存左右有效几何，再移除覆盖键。左右对齐只同步几何，不强制颜色相同。首页颜色操作写第一对，单侧页仅写该侧；ARGB透明度与全局触钮可见度相乘。固定手势波形/箭头不读取触钮色值。

## 当前边界

这次重构对齐菜单层级和已实现能力，并不声明三星专属能力已全部复刻。S Pen、外屏、三星GTS、系统手势适配未做无效占位；“适配键盘”的原义是向上移动触钮，当前仅保留真实的“键盘显示时隐藏”，没有冒用同名。快速工具点击滑块、触控板透明度、快速启动悬停启停等原版独立开关尚未新增；现有运行行为保留。额外触钮的默认动作与原版新建默认值不同，以保留本工程先前接受的设置为准。

## 验证

本次独立运行了全源码 javac 和配置/几何 harness：111 项通过。包含菜单状态/长滑/颜色往返、原默认动作不变、legacy几何迁移、双侧联动、额外段隔离、滑条边界、OHO参数范围与旧值兼容。这里仅运行离线测试，视觉、触摸和 GPU 材质结果见设备记录。
