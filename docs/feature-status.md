# 功能说明

Color Hand Operation 的核心是侧边手势。先把常用动作放到顺手的位置，再按需要加工具面板和小组件，不必一次配完所有选项。

## 手势怎么分配

左右两侧各支持 3 段触钮。每段有直滑、上斜滑、下斜滑，短滑和长滑分别设置，一共 36 个动作位置。额外触钮默认关闭，可以按需要添加。

触发区域的宽度、大小、位置和颜色都能调整，设置时屏幕边缘会显示预览。短滑与长滑有各自的方向角度，还可以调整触发距离、长滑时间和振动。

不想让手势干扰某个应用，可以把它加入应用例外；也可以选择在桌面、通知面板、键盘弹出或横屏时隐藏触钮。

在「手势设置」「触钮范围」或「手势角度」打开**手势试划**，从已启用的真实触钮滑动。结果显示触钮、方向、长短滑和对应动作；点「判定数据」可看距离、角度和持续时间。试划期间手势只报告结果。

「高级设置 → 按应用设置」可以给某个应用的单个动作位置指定覆盖值。其余位置继承全局；选「无」会让该位置不执行动作，选「继承全局」会撤销这一条覆盖。应用例外仍会停用整包手势。应用详情里的试划入口按该应用的映射报告结果。

## 工具和面板

| 功能 | 当前支持 |
| --- | --- |
| 快速工具 | 12 个自定义按钮、亮度与自动亮度、音量、媒体控制。一次性动作默认用玻璃底，可在快速工具设置里开启「一次性动作使用强调色」 |
| 音量按钮 | 加减音量，长按连续调整。空闲时随系统音量条收起。点窗外时，按钮立即开始退场，点击交给原窗口；展开的系统混音面板可以继续操作 |
| 小组件 | 添加真实 Android 小组件，分页、移动、缩放和页面管理 |
| 快速启动 | 应用、动作、快捷方式和文件夹；最近应用页按包去重，从「全部任务」进入完整任务卡 |
| 任务切换 | 读取系统最近任务、显示已有快照、切回对应任务 |
| 虚拟触控板 | 相对移动光标，支持单击、双击、长按和双指滚动。触摸区和按键共用快速工具的玻璃亮度，标题居中 |
| 虚拟导航键 | 1–5 个自选动作，白色图标按可见笔画居中。整列沿触发侧排列，以手势起点的高度为中心，靠近屏幕上下端时限位。默认点击范围 58dp，圆钮直径 46dp；顶部拖动调高低，点按关闭 |
| 键盘快捷键 | 按前台应用保存组合键 |
| 屏幕工具 | 系统屏幕放大、带控制区的放大面板、屏幕自由移动 |

直接执行「屏幕超时」时，点窗外会收起选项并操作当前应用。从快速工具进入时，第一次点窗外只关时间列表。

快速工具、小组件、快速启动和任务切换器打开后，点空白处只收起最上层。浮窗里的菜单也按这个顺序收起，底下的应用停在原来那一页。添加小组件时，如果需要系统授权或提供方设置，会单独打开对应页面。

虚拟导航键、虚拟触控板和屏幕放大镜可以留在屏幕上。点窗外可以直接操作当前应用，也可以切到其他应用或临时调出快速工具。用完点工具上的关闭键。放大镜跟随系统倍率，系统停用放大时收起。息屏、关闭手势总开关或退出服务也会收起这些工具。

在动作目录选择「快速启动文件夹」即可绑定已有文件夹。绑定跟随文件夹 ID。开启对应的「快捷操作」时，可以继续滑到入口，松手执行；设置为松手触发时，打开文件夹后点选。已删除的目标会在手势设置里标出。

系统设置、无障碍、热点和护眼集中在「打开系统页面」，搜索时仍能直接选中。导航键选择器优先列常用导航，其他动作可搜索或展开。

首页「面板与工具」收录了这七类设置。点开某个手势方向，可以搜索 59 个固定动作（含“无”），也可以指定应用、应用快捷方式或快速启动文件夹。点动作名称分配手势，点齿轮打开设置，返回时会保留搜索结果和位置。部分动作依赖 Root 或 ColorOS 接口。

## 配置与小组件

配置可以导入、导出，旧格式会在导入时检查和转换。恢复手势默认值会保留面板布局、快捷方式和已经绑定的小组件。

小组件绑定属于安装应用的 UID。换包名或从别的应用迁移时，需要重新绑定，不能直接复用旧实例 ID。第三方小组件的配置页面和内容由对应应用提供。

## 在一加上试过的部分

已测试返回、最近任务、音量手势、快速工具、小组件、亮度切换、应用快捷方式、文件夹、任务恢复、触控板点击、导航键和屏幕放大。也检查过视频播放时打开浮层、横屏工具布局，以及配置导出再导入。

后台恢复测试覆盖了划掉任务卡片和进程被结束后的重连；没有做完整的长时间耗电测试，也不保证“强行停止”后还能自动恢复。各次测试的版本、步骤和结果放在[开发笔记](README.md)，不会把历史测试次数当成新版回归结果。

## 还没补齐的地方

- Samsung Wallet、S Pen、模式与日常程序等三星专属功能没有接入。
- 热点和护眼目前打开系统设置，不是直接开关。
- 三星多窗口操作、临时隐藏触钮动作、旧式 `CREATE_SHORTCUT` 配置向导和工作资料选择尚未支持。
- 触控板透明度、快速启动悬停开关、键盘上移等设置与 OHO+ 仍有差别。
- 折叠屏外屏、副用户、其他机型及全部动作组合还没有测全。

更细的对照在 [OHO+ 功能表](oho-feature-matrix.json) 和[设置实现说明](oho-settings-implementation.md)。
