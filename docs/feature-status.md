# 功能说明

Color Hand Operation 的核心是侧边手势。先把常用动作放到顺手的位置，再按需要加工具面板和小组件，不必一次配完所有选项。

## 手势怎么分配

左右两侧各支持 3 段触钮。每段有直滑、上斜滑、下斜滑，短滑和长滑分别设置，一共 36 个动作位置。额外触钮默认关闭，可以按需要添加。

触发区域的宽度、大小、位置和颜色都能调整，设置时屏幕边缘会显示预览。短滑与长滑有各自的方向角度，还可以调整触发距离、长滑时间和振动。

不想让手势干扰某个应用，可以把它加入应用例外；也可以选择在桌面、通知面板、键盘弹出或横屏时隐藏触钮。

## 工具和面板

| 功能 | 当前支持 |
| --- | --- |
| 快速工具 | 12 个自定义按钮、亮度与自动亮度、音量、媒体控制 |
| 音量面板 | 音量加减、长按连续调整 |
| 小组件 | 添加真实 Android 小组件，分页、移动、缩放和页面管理 |
| 快速启动 | 应用、系统动作、应用快捷方式、文件夹、排序、分页和最近应用页 |
| 任务切换 | 读取系统最近任务、显示已有快照、切回对应任务 |
| 虚拟触控板 | 映射点击，可调移动速度 |
| 导航键 | 1–5 个自选动作，横排或竖排，可调大小 |
| 键盘快捷键 | 按前台应用保存组合键 |
| 屏幕工具 | 系统屏幕放大、带控制区的放大面板、屏幕自由移动 |

动作列表有 60 个选项，含“无”，另支持指定应用和应用快捷方式。部分动作依赖 Root 或 ColorOS 接口，能选到不代表每台手机都能执行。

## 配置与小组件

配置可以导入、导出，旧格式会在导入时检查和转换。恢复手势默认值会保留面板布局、快捷方式和已经绑定的小组件。

小组件绑定属于安装应用的 UID。换包名或从别的应用迁移时，需要重新绑定，不能直接复用旧实例 ID。第三方小组件的配置页面和内容由对应应用提供。

## 在一加上试过的部分

已测试返回、最近任务、音量手势、快速工具、小组件、亮度切换、应用快捷方式、文件夹、任务恢复、触控板点击、导航键和屏幕放大。也检查过视频播放时打开浮层、横屏工具布局，以及配置导出再导入。

后台恢复测试覆盖了划掉任务卡片和进程被结束后的重连；没有做完整的长时间耗电测试，也不保证“强行停止”后还能自动恢复。各次测试的版本、步骤和结果放在[开发笔记](README.md)，不会把历史测试次数当成新版回归结果。

## 还没补齐的地方

- Samsung Wallet、S Pen、模式与日常程序等三星专属功能没有接入。
- 热点和护眼目前打开系统设置，不是直接开关。
- 三星多窗口操作、临时隐藏触钮动作、旧式 `CREATE_SHORTCUT` 配置向导和工作资料选择尚未支持。
- 触控板透明度、快速启动悬停开关、键盘上移等设置与 OHO+ 仍有差别。
- 折叠屏外屏、副用户、其他机型及全部动作组合还没有测全。

更细的对照在 [OHO+ 功能表](oho-feature-matrix.json) 和[设置实现说明](oho-settings-implementation.md)。
