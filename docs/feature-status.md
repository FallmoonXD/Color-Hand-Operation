# EdgeFlow 功能与验证状态

这是独立源码构建的新应用，包名为 `dev.edgeflow`，不需要安装 gulugulu，也不加载其 APK。界面延续已经确认的 ColorOS 17 材质；手势外观固定为 OHO+ 风格。

## 已实现

- 左右各三段独立手柄、直线及上下斜向的长短滑动，共 36 个动作位置；额外段默认关闭；应用排除、几何参数、方向边界、短/长即时触发、振动强度，以及桌面/通知栏/键盘/横屏隐藏设置。
- 快速工具的 12 个自定义按钮、亮度与自动亮度、音量与媒体控制；音量加减浮层；真实 AppWidget 小组件及页面管理。
- 快速启动支持应用、系统动作和 Android 动态/固定/静态快捷方式、文件夹、排序、分页、最近应用页，以及长滑后的悬停抬手选择。任务切换器读取系统真实任务并恢复对应任务，已加入系统现有快照的内存预览。
- 可调速度的虚拟触控板、支持1–5个自选动作及大小调整的横排/竖排导航键、按前台应用保存的键盘组合键，以及 Android 原生屏幕放大、带控制区的屏幕放大和屏幕自由移动。
- 设置导入/导出、旧配置迁移和小组件重新绑定。小组件的旧实例 ID 属于旧应用 UID，不能直接沿用。
- 0.2.0 设置首页与触钮配置采用 OHO+ 层级，功能参数从动作选择器齿轮进入；每触钮长滑开关、颜色与对齐几何已接入真实运行设置。手势波形恢复原版六方向箭头，不显示动作文字或替换成动作图标。

动作目录目前包含 **60 个选项（含“无”）**，另支持应用、系统管理的应用快捷方式及旧 Intent 快捷入口。这是实现数量，**不代表 60 项都已逐项实机验收**。

## 本轮已经取得的证据

- 系统任务快照接口已返回5个真实任务的145×320预览；面板已实测显示预览，关闭后窗口消失。快照只保存在进程内存，不写截图文件。
- 快捷方式稳定 ID 已通过14项 JVM断言；实际查询取得支付宝4项动态入口及真实图标，记录见 [shortcut-list-validation.json](../verification/shortcut-list-validation.json)。
- 全部 Java 源码可编译；截至 0.2.0，手势状态机有 68 项 JVM 断言，配置/组件迁移与几何有 111 项断言，六段手柄配置有 51 项断言，命令结果处理有 9 项断言。单元断言与实机交互验证分开计数。
- 一加上已验证左右短滑的返回/最近任务、四条音量手势、两侧小组件入口，以及不同触发点产生不同面板位置。原生材质管线已连接，支付宝小组件已在新应用下重新绑定并显示。
- 系统最近任务接口已返回真实任务；ColorOS 单手模式已成功调用。侧边栏现通过系统 ContentProvider 直接展开，已在实机显示完整系统侧边栏，不再依赖注入滑动。
- 快速启动已实测创建文件夹、添加并移入“返回”动作、打开文件夹；任务切换器已恢复同一个设置任务。触控板已完成一次真实点击；导航键已验证 Home 和横竖排列保存；系统放大已通过系统状态确认 2 倍开启及恢复，新放大控制板也已实测平移、调到2.5倍和关闭。
- 键盘组合键已在系统设置搜索框实测：通过面板发送 CTRL+A 后，后续输入替换了整个原字段。完整编辑流程、其他应用、长时间使用和生命周期的回归程度以验证记录为准。上述单项成功不代表所有交互已验收。
- 自动亮度往返切换、手动亮度写入、快速工具和音量浮层的长按连续调节、点击外部关闭均已通过实机检查。打开工具时前台 Activity 保持不变；这项检查不能代替各视频应用的播放测试。
- 此后已在 B 站实际视频中验证工具与音量浮层保持 PLAYING 状态，真实横屏下三排工具完整显示。桌面/通知面板隐藏恢复、小组件增删空页、系统文件选择器导出再导入也已通过；范围见 [实机记录](device-validation.md)。
- 后台划走应用卡片后，进程 PID 仍为 **31788**，手势和工具继续工作。为 `dev.edgeflow` 单独开启 ColorOS 自启动权限后，配合服务自身启动和 `START_STICKY`，主进程被 `kill -9` 结束时已自动恢复为新进程（**21973 → 24369**），并再次打开工具面板。
- 上述恢复验证没有修改全局自启动策略或重新打开用户关闭的无障碍服务。本轮没有实际重启设备；“强行停止应用”也不属于这次恢复验证范围。

## 与 OHO+ 尚不等价的部分

- Samsung Wallet、模式/日常程序、S Pen、三星 AI 选择、游戏工具、隐私屏幕及部分任务栏/多窗口接口没有假造替代功能。
- 屏幕自由移动已实测平移后的映射点击；放大控制区已完成平移、2.5倍和关闭检查。OHO+ 原版也是全屏变换加小型控制窗口，新应用采用 Android 无障碍接口，系统边框等仍有差异。热点和护眼提供设置入口，并非直接开关。
- 任务预览及面板关闭已通过单项实测，三星多窗口操作尚未接入。启动器固定三排、新设置提供 2/3/4 列，兼容旧 5 列配置；已增加当前用户的动态/固定/静态快捷方式选择器，并完成系统 WLAN 快捷方式从选择到手势启动的实测。旧式 CREATE_SHORTCUT 配置向导和工作资料选择尚未支持。
- 临时隐藏触钮的手势动作尚未实现。额外右侧第二段的独立动作、自定义导航通知键和原配置恢复已实测；未穷举36个动作位置及全部配置组合。折叠屏外屏配置及 OHO+ 的全部独立角度/场景参数尚未完全对应。
- 菜单层级已重构，但快速工具的点击滑块开关、触控板透明度、快速启动悬停启停、键盘上移适配等原版设置仍有差异，详见 [设置实现与边界](oho-settings-implementation.md)。

详细清单见 [oho-feature-matrix.json](oho-feature-matrix.json)，源码边界见 [oho-audit.md](oho-audit.md)，实机自动化结果见 [core-validation.json](../verification/core-validation.json) 和 [controls-validation.json](../verification/controls-validation.json)。本文件只汇总有证据的结果，不宣称已经实现完整的一比一复刻。
