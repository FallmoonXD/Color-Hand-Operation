# 0.3.7 · OHO 图标、振动、角度及应用动作设置

2026-11-06，OnePlus PKR110 / ColorOS 17，包名 `dev.edgeflow`，版本 `0.3.7-oho-controls` / code 10。

## 变更

- 暂时恢复用户提供 OHO+ 9.3.13.0 APK 的原版背景、前景和 monochrome 矢量，三个资源文件与解码原件一致。当前生成器也改回该来源，历史图稿和安装包保留。见 [原版图标记录](original-oho-icon-restoration.md)。
- 快速振动与自定义振动强度按 OHO+ 分开，使用原版小字。关闭自定义时使用 ColorOS 的系统触觉反馈；开启才显示级别滑块。级别使用原版 0–30ms 单次振动模型，界面按既定要求显示百分比。旧振幅、静音设置在用户实际修改之前保留。见 [原版行为和兼容说明](oho-haptics-angles.md)。
- 删除手势示意图及其死代码。手势角度分别配置短滑、长滑的上方外限位、向上斜滑分界、向下斜滑分界、下方外限位，直接用于识别器。未修改的范围从旧角度读取，避免升级后动作分区突变。滑块按 1° 调节，原有小数值在未触碰时仍保留。
- 所有共用滑块的标题不再拼接数值，当前值置于两端小字中间；收紧上下间距，保持 44dp 触控高度。触控宽度、大小、位置继续显示真实屏幕边缘预览。接口见 [设置控件记录](settings-gesture-controls.md)。
- “启动指定应用”和“应用快捷方式”与普通动作共用单选行、右侧设置按钮。右侧只配置目标；若当前选的是其他种类动作，不改变实际映射。左侧选择已配置目标。切换到其他动作后仍保留各自目标，配置导入导出支持这些字段。
- 应用快捷方式的应用列表、加载、空结果、错误和快捷方式列表改用同一个设置风格底部面板，显示实际应用/快捷方式图标；退场并清理旧窗口后才提交选择。后台或取消不会提交。服务浮层继续保留非焦点窗口，避免影响媒体播放。

离线构建通过。生产手势/计时/角度/兼容逻辑 339 项、配置与归档 184 项、数值显示 19 项、快捷方式身份与协议 28 项断言通过。

`tools/verify_external_action_ui.py` 已验证两类齿轮独立配置、左侧选择、切换其他动作后保留目标、快捷方式取消不修改映射；手势动作和快捷方式标签缓存均精确恢复。最终版另外收去“动态/静态”等内部类型说明，保留不可用原因。

设备框架已实际渲染安装 APK 的普通自适应与 monochrome 图层。安装版本、APK SHA-256、四份偏好存储和工具布局已读回核对，配置与本轮开始时一致，无障碍仍开启，当前进程无崩溃记录。

实机结果与最终包哈希记录在本机 `verification/oho-controls-*.json`，该目录不参与运行时和源码包。真实硬件的主观振感仍需用户使用评价；自动回归验证时机和调用路径，不把代码断言视作振感测量。
