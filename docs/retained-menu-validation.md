- 缩小单选圆形与标题的间距：圆形占位从 44dp 改为 40dp，标题左 padding 从 8dp 改为 0，总计向左收紧 12dp。圆形位置、行触控高度和左右整体留白保留。

- 移除“需要设置”分组小字，以蓝色文字和组间留白表示配置项。

## 保留与返回

进入齿轮配置页时 `ColorActionSheet.suspend()` 隐藏原 Dialog，保留原窗口、列表视图和滚动位置。返回原手势页后，等待现有页面退出动画真正结束，再 `resume()` 显现原列表，不播放一次新的弹层入场动画。嵌套进入快速工具按钮编辑页或切后台仍保留隐藏状态，只有回到对应手势页和历史深度才恢复。

应用和快捷方式配置完成后，在原列表内更新目标摘要与所有单选状态；点击时读取最新目标，不保留过期闭包。第一次从未配置的操作开始选择时，取消返回原列表，成功选择则完成手势设置并关闭列表。

Activity 因字体、旋转、主题等配置变化重建时，旧 Dialog 彻底销毁；Bundle 保留手势键、来源页面、历史深度和滚动位置，新实例使用 `showRestored()` 无入场恢复。尚未创建窗口的保留状态不会因一次 `onPause` 被清除。首帧尚未布局时也允许暂停保留，保存位置使用原有元数据，不把尚未恢复的 0 写回。中断页面动画的重绘也会重新安排列表恢复。

隐藏窗口的关闭必须直接移除，即使 `Dialog.isShowing()` 已为 false。主题刷新先按已有文字语义角色应用新色，再重采集，避免旧蓝色被误识别为固定颜色。
