# 工具动画

首页右上角与手势识别设置都有固定用途。动画属于工具显示设置，因此入口放在 **首页 → 面板与工具** 顶部，以独立卡片排在「面板」和「操作工具」两组之前。

「动画设置」先列出工具及其当前入场、退场样式。工具详情用「入场」「退场」切换。每行左边的小图可以单独播放，中间显示名称，右边是圆形单选按钮。动画预览和浮窗共用播放器；预览以右侧作示意，真实浮窗按照手势起点左右镜像。底部按钮同时复制入场和退场两个选项。复制「工具默认」会让各工具采用自己的预设，复制具体样式则使用同一种动画。

| 选项 | 来源与用途 |
| --- | --- |
| 系统音量条 | SystemUI 单条音量窗的显示和隐藏弹簧，操作侧决定缩放中心与平移方向 |
| 展开音量面板 | SystemUI 多列音量窗的入场时长。其退场使用与单条相同的参数，退场页只列一次 |
| 智能侧边栏 | 本机 SmartSideBar 的 `PanelMainView.applyRevealSpringParams` / `applyDismissSpringParams`。位置、宽度、高度分别按原弹簧运动。将原生触条的 4 × 60 dp 起始尺寸适配到 CHO 的固定浮窗，沿用各工具自己的玻璃和最终布局 |
| 锚点菜单 | Settings 弹出菜单的缩放和透明度弹簧，锚点放在操作侧 |
| 侧向平移 | Settings 的横向进入、返回曲线和 350 ms 时长。行程使用当前面板的宽度 |
| 原地浮现 | Settings 居中弹窗的放大淡入、原地淡出，可以选回 0.3.23 快速工具的表现 |
| 无动画 | 立即显示或收回 |

快速工具、独立音量按钮和虚拟导航键默认用系统音量条。键盘快捷方式、独立屏幕超时与兼容应用启动器保留各自底部弹层预设，屏幕自由移动默认保留画面复位。这里配置的是 CHO 自绘的工具窗口；系统自己的音量条、输入法和外部应用由对应进程控制。系统动画倍率继续生效。

每个工具用稳定 ID 分别保存入场和退场。批量覆盖在一次配置写入内完成，导入时会先校验全部 ID 和样式。恢复手势默认设置会保留工具动画。窗口关闭时原有的触摸归属、系统销毁和一次性动作回调顺序继续由窗口所有者管理。

实机可运行 `tools/verify_native_motion.py` 比对设备原生参数，再运行 `tools/verify_tool_animations.py` 检查预览、独立选择、批量覆盖和真实浮窗。签名包读取原配置时按[动效对照](coloros17-motion.md)设置测试环境变量。
