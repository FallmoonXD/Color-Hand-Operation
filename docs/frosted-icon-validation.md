# 0.3.14 整体柔和材质与主题图标

日期：2026-11-06。`dev.edgeflow`，`0.3.14-frosted-icon` / versionCode 17；OnePlus PKR110，ColorOS 17。

## 本轮调整

彩色图标保留 OHO+ 手机、屏幕、前后手和袖口的原始路径，只保留这些原有色块与渐隐箭头。删除 0.3.13 中逐部件的描边、窄亮边、接触阴影、掌心明暗和反射带。所有部件使用同一坐标范围的柔和渐变，先完整绘制再以整个 drawable 的 0.74 alpha 合成，形成整体乳白透色；没有单独给手增加几何或明暗结构。紫橙背景保持不变。这是图标的柔和材质设计，没有运行系统模糊或 OEM 着色器。

MD3 单色层使用真实的屏幕填充，而不是空心框；同一系统主题色通过 alpha 区分各部分：屏幕 .38、机身 .66、前手 1、后手 .84、袖口 .55。绘制前从下层裁掉上层覆盖的形状，避免透明度累加或手机轮廓透过手部。通知小图标保留独立的高对比轮廓，资源哈希与 0.3.13 相同。

## 原生裁切修正

最初的 `clip-path fillType=evenOdd` 在 resvg 预览中正确，但当前设备的原生 VectorDrawable 绘制仍让袖口下的手部保留，袖口采样 alpha 为 255 而非 140。改为 `nonZero` 并明确令 viewport 矩形与遮挡路径反向，实机采样恢复预期。各遮挡分别裁切，避免多个重叠遮挡的绕数重新变成非零。

原 FG 手机/屏幕是负向轮廓，手/袖口为正向。修正没有改动原曲线。独立几何检查的 1,152 条扫描线、5,862 个区间没有发现分区重叠、轮廓缺失或遮挡顺序差异。

- 使用原生渲染的 alpha 制作浅色、深色着色检查图，两种背景下各部分可区分。没有修改用户的系统图标主题设置。
